Fourteen canonical skills: seven with originals, seven factory-specific.

Working iterations applies to all fourteen skills; launchers follow their selected canonical method. No new skill or phase. Two portable entries, [Safe Engine](../../skills/safe-engine/SKILL.md) and [Improve Factory](../../skills/improve-factory/SKILL.md), load the same complete bundle. Install using their [delivery](../../docs/install-safe-engine.md) or [maintenance](../../docs/install-improve-factory.md) guide.

A direct analysis/planning/review request keeps its phase. Delivery runs in [speed modes](safe-engine/references/speed-modes.md): Fast by default, Lucky or Safe on request. Fast and Lucky follow [Fast run](safe-engine/references/fast-run.md): tickets, recorded methods and the gate. Every mode meets the [product bar](safe-engine/references/product-bar.md). Safe implementation follows Ticketing and the full cycle; legacy unticketed fixes retain Small Change. [Mandatory logging](safe-engine/references/app-diagnostics.md) and [efficiency](safe-engine/references/app-efficiency.md) belong to the delivery coordinator; restored originals do not import them automatically.

All delivery and maintenance follows [tests-last order](../../docs/current-decisions.md#finish-work-use-it-then-automate-tests). Keep bounded fixes surgical. This coordination rule preserves the originals' wording.

The local controller keeps five acceptance passes. PR review is separate: [cloud PR review](../../docs/pr-workflow.md#cloud-pr-review). Discover applicable interfaces, resources and evidence; do not load unrelated reference packets.

The 38-skill source catalog is background, not 38 installed skills. [Pilot evidence](../../docs/pilot-verification.md) is dated; packaging a rewritten skill does not demonstrate a new app run.

[Clear Writing](safe-engine/references/clear-writing.md) applies to authored output: brief, natural, specific, evidenced. One shared rule; no extra skill or review stage.

[Ticket/PR writing](safe-engine/references/work-writing.md): clear purpose/goal, context, change/reason, proof and progress; concise bullets, emojis, tables and flows. Shared layout, no new phase.

[Public Web SEO](ux-quality/references/web-seo.md) covers public pages intended for search. Shared checklist from planning through verification; private/staging routes retain exclusions.

[Application Security](safe-engine/references/app-security.md) covers proportional early protections and production checks through the existing security code review.

[Delivery Readiness](safe-engine/references/delivery-readiness.md) owns baseline Working iterations. Other sections apply conditionally: capabilities, manual/mixed evidence, intended game challenge, browser lifecycle, durable integrations and authorized release/operations. No new skill or phase. Product pilots/simulations remain deferred until requested.
