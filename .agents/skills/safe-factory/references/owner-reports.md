# Plain owner reports

Use for progress updates and delegate handbacks, not direct answers. Run files and tickets keep their identifiers.

1. Page or feature, what changed in user words, next action, worth-it score, estimated time left, who waits on whom. No ticket or criterion codes, branch names, hashes, unexplained abbreviations in body. Reference links last.
2. Time and tokens: what host measures, labeled measured, estimated or unavailable. Never split a shared session total across tickets or invent telemetry.
3. Visual change: current picture, after inspecting it. Blank, corrupt or wrong screen: recapture.
4. Use `deep-review` worth inputs; no duplicate score formula. Missing worth inputs show unavailable with a reason.
