# PR closed unmerged

At intake, per closed unmerged PR: each open ticket it names with a closing keyword gets an activity entry (what PR did, why closed), unless activity already records that PR's closing.

- Another open or merged PR names it: note that superseding PR.
- Otherwise, only while ticket still sits where that PR left it (Dev done or Ready for QA with that PR linked, no status change since close): back to Backlog, or closed as not planned when owner's closing note says no longer needed.
- Ticket that moved on keeps its status.
- Redo request in that note = change of intent for the run that takes it.
