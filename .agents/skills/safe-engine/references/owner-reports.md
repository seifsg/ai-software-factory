# Plain owner reports

Use for progress updates and delegate handbacks, not direct answers. Run files and tickets keep their identifiers.

1. Name the page or feature, what changed in user words, the next action, worth-it score, estimated time left and who waits on whom. No ticket or criterion codes, branch names, hashes or unexplained abbreviations in the body. Put reference links last.
2. Time and tokens: show what the host measures; label measured, estimated or unavailable. Never split a shared session total across tickets or invent telemetry.
3. Visual change: include the current picture, after you inspect it. Reject blank, corrupt or wrong-screen images; recapture instead.
4. Use `deep-review` worth inputs; no duplicate score formula. Missing worth inputs show unavailable with a reason.
